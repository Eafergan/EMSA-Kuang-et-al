These are the codes used to generate figures 1 and 2 in the PLoS Genetics 2021 papers
for figure 1:start with "EMSA_Fit_fig1.m"
the parameters are extracted using a costume gradient descent fit simultaniusly on three occupation states equations
The statistics are generated using bootstrap method as described in the paper.
then use "figure_builder_fig1.m" to use the extracted parameters to generate the plot used in figure 1

For figure 2: use "Fit_fig2.m"
